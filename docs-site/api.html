API reference

Every method NCToolkit exposes, grouped by what it does. Unless noted otherwise, methods are called on a DataSet object (what open_data() and friends return).

Session options

options(...)Set global session settings — cores, temp_dir, progress, lazy, parallel. See Global settings.

Opening & copying data

open_data(path)Open one or more local netCDF files. Accepts a path, list, or wildcard.
open_url(url)Download a file from a URL or ftp address, then open it.
open_thredds(url)Open data served over a thredds/OPeNDAP endpoint (must end in .nc).
open_geotiff(path)Open a GeoTIFF file as a dataset.
from_xarray(ds)Create a dataset from an existing xarray Dataset.
create_ensemble(dir)List the files in a directory as an ensemble, for use with open_data or parallel processing.
DataSet.copy()Return an independent copy of a dataset.

Accessing attributes

DataSet.variablesVariable names in the dataset.
DataSet.contentsDataframe of variables, units, long names and data types.
DataSet.times / years / monthsTime steps / years / months present.
DataSet.levelsVertical levels present.
DataSet.sizeSize of the dataset's temporary file(s).
DataSet.currentCurrent temporary file(s) representing dataset state.
DataSet.historyCDO command(s) generated by operations run so far.
DataSet.startStart date of the dataset.
DataSet.calendarCalendar type used by the time axis.
DataSet.ncformatnetCDF format of the underlying file(s).

Subsetting & time-based methods

DataSet.subset(...)Select variables, years, months, seasons, timesteps or a lon/lat box. See Subsetting data.
DataSet.crop(...)Geographic subsetting to a lon/lat box.
DataSet.drop(...)Drop specific times, e.g. leap days.
DataSet.set_date(...)Set/override the start date of a dataset.
DataSet.set_day(...)Set the day-of-month used for time steps.
DataSet.shift(...)Shift time forward or backward by hours, days, months or years.

Statistical methods

Temporal statistics (prefixed t), each accepting an optional over grouping of "day"/"month"/"year"/"season" — see Temporal statistics:

DataSet.tmean / tmin / tmax / tmedian / tsum / trange / tstdev / tvar / tpercentile / tcumsumMean, min, max, median, sum, range, standard deviation, variance, percentile, or cumulative sum over time.
DataSet.rolling_mean / rolling_min / rolling_max / rolling_sum / rolling_range / rolling_stdev / rolling_varThe same statistics over a moving window of time steps.
DataSet.annual_anomaly / monthly_anomalyAnomaly relative to a baseline period, absolute or relative, optionally smoothed with a rolling window.

Spatial and zonal statistics:

DataSet.spatial_mean / spatial_min / spatial_max / spatial_sum / spatial_range / spatial_stdev / spatial_var / spatial_percentileStatistic across the horizontal domain at each time step.
DataSet.zonal_mean / zonal_min / zonal_max / zonal_range / zonal_sumStatistic along lines of latitude.
DataSet.meridonial_mean / meridonial_min / meridonial_max / meridonial_rangeStatistic along lines of longitude.
DataSet.centre()Centre a variable by removing its spatial mean.
DataSet.cor_space(...) / cor_time(...)Spatial or temporal correlation between variables or datasets.

Vertical methods

DataSet.top() / bottom()Select the surface (or sea-floor) vertical level.
DataSet.vertical_interp(levels, fixed)Interpolate to specified vertical levels.
DataSet.vertical_mean / vertical_min / vertical_max / vertical_range / vertical_sumStatistic across vertical levels, thickness-weighted where available.
DataSet.vertical_integration()Full water-column total, accounting for cell thickness.
DataSet.vertical_cumsum()Cumulative sum with depth/height.
DataSet.invert_levels()Reverse the order of vertical levels.
DataSet.bottom_mask()Mask indicating the deepest valid level at each point.

Interpolation, matching & resampling

DataSet.regrid(target, recycle=False)Regrid onto another dataset's grid, a netCDF file's grid, or a dataframe of lon/lat coordinates.
DataSet.to_latlon(lon, lat, res, method)Regrid to a regular lon/lat grid with a given extent and resolution.
DataSet.resample_grid(n)Coarsen the horizontal grid by keeping every nth cell.
DataSet.fill_na(n)Distance-weighted infilling of missing values using n nearest neighbours.
DataSet.time_interp(...) / timestep_interp(...)Interpolate onto a new time axis, by date or by timestep.
DataSet.box_mean / box_max / box_min / box_sum / box_rangeStatistic within a set of geographic boxes.
DataSet.mask_box(...)Mask a dataset outside a geographic box.

Point matchups & ecological methods

DataSet.match_points(df, variables=None, tmean=False, top=False, nan=None)Match gridded data to a dataframe of point observations (lon/lat/depth/year/month/day). See Matchups with point data.
DataSet.phenology(...)Calculate phenological metrics (e.g. bloom timing) from a time series.

Ensembles & merging

merge(datasets, ...) / DataSet.merge("time"|"variable")Combine multiple files by matching time steps or by stacking variables. See Ensembles & multi-file datasets.
DataSet.split(...)Split a dataset back out into separate files.
DataSet.append(...) / remove(...)Add or remove member files from a multi-file dataset.
DataSet.ensemble_mean / ensemble_min / ensemble_max / ensemble_sum / ensemble_range / ensemble_stdev / ensemble_var / ensemble_percentileStatistic calculated across ensemble members, e.g. across climate models.

Arithmetic & comparisons

DataSet.add / subtract / multiply / divideElementwise arithmetic against a constant or another dataset. Also available as +, -, *, /.
DataSet.abs / exp / log / log10 / sqrt / square / power(n)Elementwise mathematical transforms.
DataSet.compare(">0")Elementwise logical comparison against a constant or dataset; also available as >, <, ==, >=, <=, !=.
DataSet.gt(...) / lt(...)Explicit greater-than / less-than comparisons.
DataSet.sum_all()Sum all variables in a dataset into one.

Variable & attribute editing

DataSet.assign(...)Create new variables from lambda functions, pandas-style. See Mathematical operations.
DataSet.rename({old: new})Rename one or more variables.
DataSet.as_missing(...) / missing_as(...) / set_fill(...)Set values to missing, replace missing values, or change the netCDF fill value.
DataSet.set_longnames(...) / set_units(...)Edit a variable's long_name or units netCDF attribute.
DataSet.strip_variables(...)Remove non-essential variables from the dataset.

Plotting

DataSet.plot(...)Automatic interactive plot — map, time series, or heatmap depending on the data's shape. See Visualization.
DataSet.pub_plot(...)Static, publication-quality plot for regular lon/lat grids.

Output & formatting

DataSet.to_nc(path)Write the dataset to a netCDF file.
DataSet.to_dataframe()Convert the dataset to a pandas dataframe.
DataSet.to_xarray()Convert the dataset to an xarray Dataset.
DataSet.zip()Mark the dataset to be written as a compressed netCDF file on export.
DataSet.format(fmt)Set the netCDF format: nc1, nc2/nc, nc4, nc4c, nc5.

Evaluation & cleanup

DataSet.run()Force evaluation of any pending lazy operations. See Lazy evaluation.
cleanup()Remove NCToolkit's own temporary files from the current session.
deep_clean()Remove all NCToolkit temporary files, including from other sessions.
DataSet.reset()Reset a dataset back to its originally opened state.

Miscellaneous

DataSet.check()Run general sanity checks: integer types, integer time axis, CF-compliance, grid consistency. See Troubleshooting.
DataSet.is_corrupt()Check whether the source file(s) are corrupt.
DataSet.assign_coords(lon_name, lat_name)Tell NCToolkit which variables to treat as longitude/latitude coordinates.
DataSet.set_precision(dtype)Change the numerical precision used for calculations, e.g. "F64".
DataSet.set_gridtype(...) / fix_nemo_ersem_grid(...)Correct grid-type metadata, including a helper for NEMO-ERSEM output.
DataSet.reduce_dims() / reduce_grid(...)Drop length-1 dimensions, or reduce an unnecessarily large grid.
DataSet.surface_mask(...)Generate a land/sea mask from the surface level.
DataSet.no_leaps()Remove leap days from the time axis.
DataSet.as_double() / as_type(dtype)Cast the dataset to double precision, or a specific data type.
DataSet.na_count() / na_frac()Count, or fraction, of missing values.
DataSet.first_above(...) / first_below(...) / last_above(...) / last_below(...)First/last time step crossing a threshold.
DataSet.distribute(...) / collect(...)Split processing across, then gather results back from, worker files.
DataSet.cell_area(join=True)Add (or return only) grid-cell area in m².
DataSet.cdo_command(cmd, ensemble=False) / nco_command(cmd)Run a raw CDO or NCO command. See CDO & NCO backends.
