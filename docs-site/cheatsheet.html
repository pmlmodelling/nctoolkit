How to

Common tasks, one line of code each. Every example assumes import nctoolkit as nc and a dataset ds opened with nc.open_data(). The tag on each card links to the method's full entry in the API reference.

Opening data

Opening a file

open_data
ds = nc.open_data("foo.nc")

Opening several files as one dataset

open_data
ds = nc.open_data(["foo1.nc", "foo2.nc"])

Opening every file that matches a pattern

open_data
ds = nc.open_data("data/*.nc")

Opening a file on a THREDDS server

open_thredds
ds = nc.open_thredds("https://foo.nc")

Downloading a file and opening it

open_url
ds = nc.open_url("https://foo.nc")

Converting an xarray dataset

from_xarray
ds = nc.from_xarray(xr_ds)

Copying a dataset

copy
ds2 = ds.copy()

Opening a GeoTIFF

open_geotiff
ds = nc.open_geotiff("foo.tif")

Listing every netCDF file in a directory

create_ensemble
files = nc.glob("data/foo")
